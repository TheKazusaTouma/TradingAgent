# OpenCode working rules — draft

Before implementation, read `AGENTS.md`, the relevant approved requirements, and affected code. Preserve unrelated changes. Use a reviewable branch, make small scoped changes, and run the relevant checks. Explain observed failures and limits rather than silently weakening tests. Do not disclose credentials or include them in commits or transcripts intended for sharing.

The draft root `opencode.jsonc` references this file. Verify that the installed version resolves the configuration and test individual permissions before claiming enforcement. See the project's permission manifest and `docs/architecture/permission-model.md`.
