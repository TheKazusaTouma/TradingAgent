# Project covenant — draft

1. A human owns requirements, acceptance decisions, and review; the coding agent assists under that direction.
2. Retain traceable evidence linking each approved requirement to design, implementation, and verification.
3. Do not invent evidence, test results, approvals, contributors, or agent-session history.
4. Protect credentials and private data; inspect final artifacts before submission.
5. Distinguish observed behavior from proposed requirements and unverified assumptions.
6. Follow the course's OpenCode requirements and accurately record any other tool used.

These are proposed operating rules; this file alone cannot enforce permissions or GitHub protections.
