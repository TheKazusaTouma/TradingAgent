# Coding-agent transcripts — required team input

This folder currently contains **no student transcripts**. The course slides describe full session transcripts as primary evidence of human direction and show annotated per-student Markdown files. The detailed Project Requirement Sheet may impose additional requirements.

## Collection procedure

1. Each member identifies their actual sessions, project path and coding agent. Do not attribute a session to a tool or person without evidence.
2. Preserve the original full export in a private, access-controlled location. Confirm the instructor's rule for redacting secrets and submitting full transcripts before deleting or altering any source evidence.
3. The installed OpenCode's `opencode export --help` advertises `opencode export [sessionID]` and `--sanitize`; consult the version's own help and verify that the selected session and output are correct. Sanitization can remove content, so an export using it must not be assumed to be the complete original.
4. Create the instructor-required annotated Markdown file named `<student-id>-<student-name>.md`, linking the student's actual decisions, prompts, reviews, fixes and tests to the original evidence. Never invent a conversation or claim an agent was used when it was not.
5. Separately record the Codex integration, Windows test fix and preparation of this draft if the instructor requires all agent use to be disclosed. Ask the instructor about mixed-agent handling where unclear.
6. Inspect final exports for API keys and private information; do not commit or publish credentials. Agree with the instructor how required full evidence and redaction should coexist.

Student names, IDs, session IDs, complete transcripts, and approvals are not present in this draft and must be supplied by the members themselves.

Their ownership, relevance, completeness, and redaction have not been reviewed. They were not added to this draft or submitted; the source sessions remain in OpenCode. These review copies do not establish that all four members' complete transcripts have been collected.
